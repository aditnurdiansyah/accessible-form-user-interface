# Accessible Form User Interface

## Project Overview

This project involves creating a modern, accessible, and responsive **Accessible Form UI** component using semantic HTML and CSS. The primary objective is to build an inclusive and accessible form interface that ensures a seamless user experience for everyone, including users relying on screen readers and keyboard navigation.

The project focuses on building a semantic and accessible web component while applying essential frontend practices such as web accessibility (WCAG standards), SEO meta tags, Open Graph (OG) integration for social sharing, favicon implementation, Google Fonts integration, and responsive CSS layout optimization.

## Project Requirements

* **Semantic HTML & Accessibility Attributes**
  Use semantic HTML form elements along with appropriate ARIA attributes to ensure screen reader compatibility and logical document structure.

* **Search Engine Optimization (SEO) Meta Tags**
  Include essential metadata inside the `<head>` section to improve discoverability and search engine indexing.

* **Open Graph (OG) Tags**
  Implement Open Graph tags to provide optimized previews when sharing links on social media platforms.

* **Favicon**
  Add a favicon for better branding and browser recognition.

* **Responsive Layout Preparation**
  Organize the layout using CSS grid, flexbox structure, and media queries to support all screen dimensions, from desktop down to mobile devices.

* **Form Validation & Interactive States**
  Design distinct visual focus outlines, hover/active states, visual error feedback, and accessible form input controls to provide clear guidance during user interaction.

## Project Structure

* **Homepage (`index.html`)**
  The primary HTML document containing the accessible form structure, input controls, fieldsets, accessible labels, and action buttons.

* **Styles (`css/style.css`)**
  Contains custom CSS styling, form alignment, accessible focus rings, error indicators, and responsive layout adjustments.

* **Assets (`assets/`)**
  Directory containing project icons, favicons, Open Graph images, and `project-preview.png`.

## How to Use

1. Clone or download this repository.

```bash
git clone https://github.com/aditnurdiansyah/accessible-form-user-interface
```

2. Navigate to the project folder.

```bash
cd accessible-form-user-interface
```

3. Open `index.html` in your browser.

4. Customize the styling, input controls, and form validation states according to your UI/UX application requirements.
